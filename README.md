# ObeBot - A Simple Slack Helper Bot

## How to Use
You can test the bot out on Hack Club's Slack workspace, in the **[bot-spam channel](https://app.slack.com/client/E09V59WQY1E/C0P5NE354)**.

Try running ```/obebot-help``` to see what commands you can use.

## Slash Commands
1. ```/obebot-ping``` - Check bot latency
2. ```/obebot-future``` - Send a message to the (near) future
3. ```/obebot-help``` - Displays a list of commands you can use. You can also type ```/obebot-help [command name]``` to look at a specific command.
